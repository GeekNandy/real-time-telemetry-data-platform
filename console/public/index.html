Reading this console
Scope
Event APIs derive tenant identity from the JWT. Aggregate metrics require the separate telemetry.observe scope.
Freshness
Snapshots refresh every five seconds while the overview is visible. Missing and unavailable values remain unknown. Counter resets start a new rate series.
Guarantee
Acceptance depends on the collector volume surviving until Kafka acknowledgement. Readiness and a green trace do not establish replicated acceptance or high availability.
Local access
The observability profile provisions Grafana and Prometheus. Grafana requires its generated local administrator password. These links use the current host and published demo ports.
